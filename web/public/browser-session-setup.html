Connect your YouTube browser session

Set up once in Chrome or Edge. Future link imports and retries refresh your YouTube session automatically. The video downloads and processing still run entirely on OCI.

  1. Download the extension ZIP and extract it to a folder you will keep.
  2. Open chrome://extensions or edge://extensions. Enable Developer mode, click Load unpacked, and choose the extracted folder containing manifest.json.
  3. Sign in to YouTube in the same browser profile.
  4. Reload VI Clips, open New project → YouTube URL, and enable Use my YouTube browser session. This preference is remembered in that browser.
  5. Paste a link and import. Use Check connection to test session sharing without downloading a video.

What is shared

The extension reads only youtube.com cookies, including the login cookies needed for an authenticated download. It does not read Google, email, passwords, other websites, or browsing history. Cookie values are passed from the isolated extension script directly to VI Clips and are never included in page messages or browser storage.

The app proxy sends the session through your existing private SSH tunnel to OCI. The backend encrypts it at rest and deletes its temporary download cookie file after use. A YouTube session can grant account access, so use this connection only with your own private VI Clips server.

Disconnect

In the import dialog, choose Disconnect and remove saved session. This disables automatic sharing for that browser and removes the encrypted server copy. Remove the extension from the browser's extensions page to revoke its cookie permission completely. Turning off only the checkbox stops future sharing from that browser; previously queued connected imports can still use the saved server session.

Limits

This extension supports the current private app at localhost:3166 or 127.0.0.1:3166. It works in the installed browser profile only. YouTube can still reject an OCI IP even with a valid session. It cannot silently install itself or bypass the browser's initial permission grant.
